¿Qué es Internet?

Internet es una red global descentralizada de computadoras y dispositivos interconectados entre sí. Funciona como una infraestructura digital que permite el intercambio masivo de información, datos e hipertextos a través de protocolos estandarizados (como TCP/IP), haciendo posible servicios como la navegación web, correo electrónico y streaming.

¿Qué son los Proveedores de Internet?

Un Proveedor de Servicios de Internet (ISP, por sus siglas en inglés) es la empresa comercial u organización que brinda a los usuarios acceso a la red. Actúan como el puente entre nuestros dispositivos domésticos o móviles y la infraestructura global de internet, gestionando la conectividad y el ancho de banda.

Tipos de Proveedores de Internet

Los proveedores ofrecen conexión según la tecnología empleada para transmitir la señal:

  • Fibra Óptica: Transmite datos mediante pulsos de luz, ofreciendo altísima velocidad y estabilidad.
  • Satélital: Envía datos vía microondas desde antenas hacia satélites, ideal para zonas rurales o alejadas.
  • Móvil (4G/5G): Conexión inalámbrica a través de antenas de telefonía celular.
  • DSL / Cable: Utiliza las líneas telefónicas tradicionales o las redes de televisión por cable.

Carpeta Local vs Carpeta Remota

La carpeta local se refiere al directorio almacenado físicamente dentro del disco duro o memoria de tu computadora, accesible únicamente desde ese equipo sin requerir conexión a la red. Por el contrario, la carpeta remota reside en un servidor o computadora distante (como la nube o un servidor web); para acceder, modificar o subir archivos en ella es obligatorio estar conectado a internet.

Experiencia de Usuario (UX) Vs Interfaz de Usuario (UI)

La UI (User Interface) comprende los elementos visuales interactivos con los que el usuario interactúa en una pantalla: botones, colores, tipografías y maquetación. Por otro lado, la UX (User Experience) se enfoca en cómo se siente el usuario al navegar; analiza la usabilidad, la facilidad de flujo y la satisfacción general al resolver una necesidad dentro de la aplicación o sitio web.

¿Qué es Maquetación Web?

Es la fase de desarrollo donde se traduce un diseño gráfico o boceto a código fuente ejecutable por los navegadores. Consiste en estructurar el contenido con etiquetas semánticas de HTML y aplicarle formato, posiciones y adaptabilidad mediante hojas de estilo CSS para que la página sea funcional y visualmente correcta en cualquier dispositivo.

¿Qué es el Modelo de Cajas en HTML y CSS?

El modelo de cajas (Box Model) es el patrón fundamental sobre el cual se renderizan todos los elementos en un navegador web. Considera a cada elemento HTML como una caja rectangular compuesta por cuatro capas envolventes:

  1. Content: El área del texto o imagen.
  2. Padding: Espacio transparente entre el contenido y el borde.
  3. Border: Línea limítrofe alrededor del contenido y relleno.
  4. Margin: Espacio exterior transparente que separa la caja de otros elementos contiguos.
